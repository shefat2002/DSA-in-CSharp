# DSA-in-CSharp


## Data Structures & Algorithms 

**01. Arrays & Strings**
* Dynamic Arrays / Re-implementing custom `ArrayList` / `List<T>`
* Two Pointers technique & Sliding Window pattern
* String manipulation & StringBuilder implementation



**02. Linked Lists**
* Singly Linked List (Insert, Delete, Reverse, Cycle Detection)
* Doubly Linked List
* Circular Linked List


**03. Stacks & Queues**
* Stack implementation (using Array & Linked List)
* Queue implementation (using Array & Linked List)
* Circular Queue & Monotonic Queue
* Priority Queue / Min-Max Heap


**04. Searching Algorithms**
* Linear Search
* Binary Search (Iterative & Recursive)
* Binary Search on Answer Space (e.g., Search in Rotated Sorted Array)


**05. Sorting Algorithms**
* Bubble, Insertion, Selection Sort
* Merge Sort & Quick Sort
* Heap Sort
* Counting Sort & Radix Sort


**06. Recursion & Backtracking**
* Recursion Basics (Factorial, Fibonacci, Subsets)
* Permutations & Combinations
* N-Queens Problem, Sudoku Solver

**07. Trees & Binary Search Trees (BST)**
* Binary Tree Traversals (In-order, Pre-order, Post-order, Level-order)
* BST Operations (Insert, Delete, Search)
* Tree Depth, Height, Balanced Tree Checks (AVL Concept)
* Lowest Common Ancestor (LCA)


**08. Heaps & Disjoint Set (Union-Find)**
* Binary Heap (Min-Heap / Max-Heap from scratch)
* Disjoint Set Union (DSU) with Path Compression & Rank


**09. Graphs**
* Graph Representation (Adjacency Matrix & Adjacency List)
* BFS (Breadth-First Search) & DFS (Depth-First Search)
* Topological Sort (Kahn's Algorithm & DFS)
* Shortest Path: Dijkstra’s Algorithm, Bellman-Ford
* Minimum Spanning Tree (MST): Kruskal’s & Prim’s Algorithms


**10. Dynamic Programming (DP)**
* 1D DP: Climbing Stairs, House Robber, Coin Change
* 2D / Grid DP: Unique Paths, Longest Common Subsequence (LCS)
* Knapsack Problems (0/1 & Unbounded)
* Longest Increasing Subsequence (LIS)


**11. Greedy Algorithms**
* Activity Selection / Interval Scheduling
* Fractional Knapsack
* Huffman Coding


**12. Advanced Structures & Bit Manipulation**
* Trie (Prefix Tree)
* Segment Tree / Fenwick Tree (Binary Indexed Tree)
* Bit Manipulation (Bitwise operations, XOR tricks, Subsets using Bits)
